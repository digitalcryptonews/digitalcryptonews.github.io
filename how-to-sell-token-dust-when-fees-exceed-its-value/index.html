How to Sell Token Dust When Fees Exceed Its Value

When fees exceed a small token balance, re-quote at low gas, use a limit order or add tokens until the sell can cover network cost; otherwise leave the dust.

The Finality DeskNov 28, 2026 · 08:39 UTC5 min read#99daf4

Start by comparing the quoted network cost with your token balance: that tells you whether a lower-gas retry, a limit order or adding tokens can make a sale viable. When the cost still exceeds the balance, leave it untouched.

CoW Swap takes network costs from the sell amount, so a quote can fail when the order cannot cover them. Settlement gas changes little with trade size. That makes the cost roughly fixed per order: doubling the amount sold roughly halves the cost as a share of the sale. The practical target is enough value to absorb that cost, not a particular token quantity.

  1. Read the quoted network cost. Compare it with the balance’s value in the quote, using the same currency for both. Note the shortfall. A quote that is only slightly underwater may become viable when gas falls; a balance far below the cost is less likely to be worth repeated attempts. The quote describes the current conditions, so treat it as a snapshot rather than a standing promise.
  2. Retry when base fees are low. Network cost falls with gas price, so wait for a quieter period and request a fresh quote. Compare the new cost with the balance again before signing. A smaller gas price can move a near-threshold sale into range, but it cannot make a deeply uneconomic order viable by itself. Avoid repeated retries while the quoted cost remains materially above the balance.
  3. Use a limit order if the sale can wait. Set the lowest price you would accept and let the order remain open until the market moves enough for the sale to cover network costs. This replaces an immediate attempt with a price condition; it does not erase the cost of settlement. For a balance whose execution can be planned over time, consider whether a cowswap TWAP fits the trade. It still needs enough value to cover network costs when orders settle.
  4. Add more of the same token if the shortfall remains. Combining balances raises the sale value while the per-order gas cost changes comparatively little. That improves the cost as a share of the proceeds. For an illustrative case, suppose the quoted network cost is about half the value of your balance. Adding an equal amount of the same token roughly doubles the sale value, bringing that cost to about a quarter of the total, all else equal. Recheck the quote because market price and gas can change while you wait.
  5. Leave the balance alone if none of those steps works. Dust that stays in your wallet costs nothing to hold on its own. Be especially cautious with an unfamiliar airdropped token: a prompt to approve it can expose you to risk, and the token’s displayed value is not a reason to approve. Do not sign an approval just to test whether the token can be sold.
  6. Confirm the result. After placing an order, open CoW Explorer and check that it appears as open or filled. An open order is waiting for its price condition; a filled order has executed. If the quote remains blocked and no order appears, the sale has not been placed. Choose a lower-gas retry, add tokens, or keep the balance rather than treating a failed quote as a completed trade.

The decision comes down to the cost share and your patience: wait for lower gas or a price move when the gap is small, add the same token when you can do so sensibly, and leave uneconomic dust untouched.

Related questions

Is it worth selling dust tokens at all?

It is worth selling only when the likely proceeds justify the network cost and effort. Compare the quoted cost with the balance, then account for the chance that a limit order may remain unfilled. If the cost exceeds the value and waiting or adding tokens is not practical, keeping the dust avoids spending more to sell it than it is worth.

Can tiny balances be swapped on Gnosis Chain more cheaply?

Possibly, but compare the actual quoted network cost on Gnosis Chain with the balance rather than assuming the chain makes the trade economical. The token must already be available there to sell; moving it from Ethereum or Arbitrum One adds another step and its own cost. Use the quote for the network where the balance sits, and compare costs before moving funds.

Other order questions

Does a cancelled limit order for dust cost anything?

It depends on how the cancellation is submitted. A cancellation that requires an onchain transaction can incur network cost even when the order never filled. Check the wallet’s transaction prompt and quoted cost before confirming; a limit order’s unfilled status alone does not tell you whether cancelling it will cost gas.

Can several small token balances be sold in one order?

Balances of the same token on the same network can be combined into one sell amount. Different tokens are separate assets and cannot simply be added together as one sell balance; each needs its own trade or a supported route. Compare the cost of those trades with their proceeds before placing them, since splitting dust across orders can multiply the per-order cost.
