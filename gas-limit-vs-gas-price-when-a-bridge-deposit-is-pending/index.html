Gas Limit vs Gas Price When a Bridge Deposit Is Pending

Gas limit vs gas price: raise both fee fields to speed a pending deposit; raise the limit only after an out-of-gas failure, which still costs gas.

The Finality DeskNov 25, 2026 · 16:22 UTC4 min read#c8f381

For a pending EVM bridge deposit, raise the gas price, not the gas limit. Block producers prioritize transactions by fee per gas, while the gas limit only caps the execution the transaction can consume.

The distinction matters because a bridge deposit is a source-chain transaction first. cBridge is a cross-chain bridge that transfers supported assets between networks through pooled liquidity or token mappings. For a pending Ethereum deposit, the celer cbridge route does not change the fee fields that determine whether the source-chain transaction gets included.

What changes the queue position: gas limit or gas price?

Gas limit caps the amount of execution a transaction may use; gas price determines how competitive its fee is for inclusion. Raising only the limit leaves a pending transaction at the same price, so it does not improve its position in the block producer’s selection.

Under EIP-1559, a transaction sets a max fee per gas and a max priority fee per gas. The base fee is set by the protocol and is burned; the priority fee goes to the block producer. The effective fee per gas is the base fee plus the priority fee, subject to the transaction’s max fee cap. A max fee that cannot cover the base fee plus the offered priority fee can prevent inclusion.

Unused gas below the limit is not charged. The limit is a ceiling, not a bid. Increasing it may allow a transaction to finish when its existing ceiling is too low, but it does not raise the fee offered for each unit of gas.

For instance, consider two otherwise identical pending deposits with the same nonce and gas limit. One has a higher max fee and priority fee; the other has only a higher gas limit. The fee-bumped transaction offers a more competitive price per gas and can be selected sooner. The larger-limit transaction offers no better fee and can remain pending.

How can you tell whether to raise the limit?

The transaction’s status decides the lever: pending means raise the price; a failed transaction with an out-of-gas error means raise the limit on a new attempt. Inspect the transaction status and execution result in the wallet or chain explorer. A pending transaction has not completed execution; an out-of-gas failure means execution ran into the transaction’s gas ceiling.

An out-of-gas failure still charges for the gas used before execution stopped. Raising the limit does not recover that fee. For a retry, estimate the required execution and set a sufficient limit; then set fees appropriate to current network conditions. A limit increase without a price increase is not a speed-up for a transaction that is still pending.

On Ethereum, a cBridge deposit that is pending at the source chain can be replaced with a fee bump. Once the transaction is included, any remaining wait is for bridge confirmations and processing, not for Ethereum gas inclusion. The source transaction’s inclusion and the bridge’s later cross-chain steps are separate parts of the transfer.

How do you replace a pending transaction correctly?

Resend the transaction with the same nonce and higher fee fields. The nonce identifies the sender’s transaction sequence; a replacement competes with the pending transaction for that same position. A new transaction with a different nonce does not replace it.

For EIP-1559 transactions, raise both maxFeePerGas and maxPriorityFeePerGas. Geth’s default price bump is 10%, so a replacement generally needs to raise each value by at least 10% over the pending transaction or nodes may reject it as underpriced. Other clients or node policies can differ, so follow the rejection message if the replacement is still refused.

Keep the gas limit sufficient for the transaction’s execution. Changing it is useful when the original transaction failed because its limit was too low; it is not part of the fee bump that improves inclusion priority. Confirm the replacement uses the pending nonce, then submit it with both fee fields increased.

Related questions

What happens if gas limit is too low?

The transaction can run out of gas and fail before completing. Gas already consumed is still charged, and the limit must be raised for a retry.

How do you cancel a pending transaction?

Send a replacement transaction with the same nonce and a higher fee. Wallets often offer a cancel action that submits a zero-value transaction to your own address, but it still has to replace the pending nonce and be included first.

Why is my transaction stuck with nonce too high?

A transaction using a higher nonce cannot execute while an earlier nonce from the same account remains unresolved. Speed up or replace the earlier pending transaction; raising the later transaction’s gas limit will not clear the nonce gap.
