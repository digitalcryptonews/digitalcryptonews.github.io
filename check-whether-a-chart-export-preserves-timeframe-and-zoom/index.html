Check Whether a Chart Export Preserves Timeframe and Zoom

A chart export preserves your analysis only if its candles, visible date range and zoom match the live view; check the axes and exported data before sharing.

The Finality DeskOct 3, 2026 · 20:20 UTC4 min read#8d5db6

To check that a chart export keeps your timeframe and zoom, compare its candle interval and visible date range with the chart on screen. An image may capture the current view, while a data export may use different settings or include a wider period. Treat the exported file as a separate output to verify, not as proof that every chart setting carried over.

For multi-panel analysis, the PooCoin guide to watching several pairs in one chart view covers the layout. The same checks apply when you export one chart or several: identify what each panel shows, then confirm that the saved output retains the intended interval and visible window.

What do timeframe and zoom mean in a chart export?

Timeframe usually means the duration represented by each candle, while zoom controls how much of the chart’s history is visible. A chart set to a five-minute candle interval can show a short intraday window or many hours of candles, depending on horizontal zoom. Those are separate settings, and checking only one can miss an export mismatch.

There is a third distinction: the selected data range. A chart might request or load a larger range than it currently displays. Zooming in can hide older candles without removing them from the loaded series. An image export typically represents a rendered view; a data export may instead contain the selected series, a requested date range, or a product-defined subset. The file format and export action determine what it can preserve.

Before exporting, record the interval shown in the chart controls and the earliest and latest timestamps visible on the horizontal axis. If the chart uses a price scale on the vertical axis, note whether it is linear or logarithmic and whether automatic scaling is enabled. These details make comparisons repeatable. A timeframe label alone does not establish that the exported chart shows the same market window or scale.

How can I verify that the exported chart matches?

Open the export and compare its visible evidence with the live chart: interval, axis endpoints, candle spacing and plotted values. For a data file, inspect the timestamps and the time difference between adjacent rows. For an image, read the axis labels and compare recognisable candles or price levels against the chart before exporting.

  • Check the candle interval. Confirm the chart control and, where available, the export’s metadata or data timestamps agree. Adjacent rows in an OHLCV file can have gaps when no trades occur, so a missing row does not by itself prove that the interval changed.
  • Check the visible window. Compare the first and last displayed timestamps. If the export includes extra rows beyond the visible chart, distinguish the exported data range from the image’s viewport.
  • Check horizontal zoom. Compare the number of visible candles and the spacing between axis labels. A different chart width or aspect ratio can change spacing without changing the underlying date range.
  • Check scale and overlays. Verify price-axis mode, plotted series, indicators and panel selection. An export can preserve the time window yet omit an indicator or capture a different panel.

Keep a small reference capture or note the settings when the exact view matters. Then export once and compare before changing the chart. If the export is a vector or image file, inspect it at its native dimensions; a resized preview can make labels look different without changing the captured data. If it is CSV, sort by timestamp and inspect the first and last records as well as the interval between consecutive records.

Why can an export lose the chart’s view?

An export can diverge because chart state and export state are not always the same. Some chart tools snapshot the rendered viewport. Others build an image from chart data and default settings, or export rows independently of the zoom level. A saved layout may also restore the pair and indicators but not the current pan position or axis range.

Browser zoom is not chart zoom. Browser zoom enlarges the page interface; chart zoom changes the range or scale inside the plot. Resizing a panel can also cause automatic price scaling or alter the number of visible candles. If an export changes after a resize, compare axis endpoints before concluding that the candle interval changed.

For a discrepancy, repeat the export after setting the interval, visible range and scale, then compare again. If a second export still differs, check whether the export action offers its own range, panel or resolution options. Use a chart image when the goal is to preserve a visual view, and a data export when the goal is to analyse values; neither format should be assumed to carry every aspect of the other. The reliable check is the file itself: its timestamps and axes reveal what the export actually kept.
