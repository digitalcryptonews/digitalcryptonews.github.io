How do I tell whether a zkSync Era token is fake?

How to spot a fake token on zkSync Era: match its contract address to the issuer’s published address, then inspect the contract and holders on the explorer.

The Finality DeskNov 23, 2026 · 19:47 UTC5 min read#9e5b2a

You can tell whether a token on zkSync Era is genuine by matching its contract address to one published by the issuer or a trusted token list, then inspecting that address on the zkSync Era block explorer. A token’s name, symbol and logo can be copied because ERC-20 deployers choose them freely; the contract address is the unique identifier on that chain.

Match the address before you swap

The address is the first check because two ERC-20 tokens can share a name and symbol while being separate contracts. Search “USDC” in SyncSwap, for instance, and you may see several tokens with the same symbol but different addresses. Only the token whose address matches the issuer’s published zkSync Era address is the one you have verified.

Find that address in the token issuer’s official website or documentation, or in the zkSync bridge token list. Confirm that the page refers to zkSync Era. Do not take an address from a chat, an ad, or a search result snippet: those can direct you to a lookalike contract.

Network matters. A token bridged to zkSync Era has a different contract address from its Ethereum version. Pasting the Ethereum mainnet address into a zkSync Era search may return no result, or lead you toward a separate token with a copied name. Start with the issuer’s zkSync Era address, then compare the full address character by character with the contract you intend to buy.

For a concrete check, say you want USDC. Open the issuer’s source and copy the address listed for zkSync Era. In your wallet or the trading interface, open the token details and compare that address with the copied one. If they differ, stop and check the source again; a matching symbol alone is not a match.

Use the explorer to inspect the contract

The zkSync Era block explorer can show whether a contract is verified, how many holders it has and when it was created. Open the explorer page for the exact address you matched, then review those details before swapping.

A verified contract lets you inspect published source code associated with the deployed contract. A long-established token with many holders is generally more consistent with a widely used asset than a newly created token with few holders. These details are clues to assess alongside the issuer’s address; a verified contract or a large holder count by itself does not identify the issuer.

A common mistake is to see a familiar logo beside a token in a wallet and assume it is the Ethereum asset. The display can be convincing, but the chain-specific address is what identifies the token on zkSync Era. Check the address instead of acting on the appearance.

A honeypot token can accept a purchase while blocking a sale through restrictions in its transfer code. The explorer may help you inspect a verified contract, but code review can require technical knowledge. A price chart or visible pool liquidity is also insufficient: scammers can seed pools so a fake appears tradable. Treat those signals as context, and keep the issuer’s published address as your primary check.

SyncSwap is a decentralized exchange, so its token search is a useful place to apply this check: matching the token address is what distinguishes the intended asset from same-symbol results. The token search feature makes SyncSwap a concrete example of why you should verify the contract before swapping.

  • Match the full zkSync Era contract address to the issuer’s published address or a trusted token list.
  • Use the zkSync Era address, not the Ethereum address.
  • Inspect the exact contract on the block explorer, including verification, holders and creation date.
  • Do not rely on a name, symbol, logo, chart or pool liquidity alone.

Apply the check in your wallet

How do I add a custom token to MetaMask on zkSync Era?

Copy the token’s zkSync Era contract address from the issuer’s official source. In MetaMask, select the zkSync Era network and use the option to import or add a custom token. Paste the address and review the token details MetaMask retrieves. Compare the displayed address with the issuer’s address before confirming. If the address cannot be matched, do not add it as the token you intend to hold.

How do I revoke a token approval on zkSync Era?

Open a trusted approval-management tool or the relevant explorer function, connect the wallet on zkSync Era, and find the spender and token allowance you want to remove. Submit a transaction to set that allowance to zero, then confirm the transaction on the correct network and check that the allowance changed. Revoking an approval limits that spender’s permission to use the token; it does not return tokens already transferred.

Can I get my funds back after buying a scam token?

A completed swap generally cannot be reversed by the exchange. If the token blocks selling, report the address to the wallet or exchange service you used and check whether an approval remains that you can revoke. Do not share your recovery phrase or pay someone promising guaranteed recovery.
