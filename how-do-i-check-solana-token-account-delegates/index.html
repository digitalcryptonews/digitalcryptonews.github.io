How do I check Solana token account delegates?

To check token approvals on a Solana wallet, inspect each SPL token account’s delegate and delegated amount on Solscan or with spl-token, then revoke unwanted delegates.

The Finality DeskNov 25, 2026 · 08:39 UTC4 min read#50d953

Inspect every SPL token account owned by your Solana wallet and look for its delegate and delegated amount. Solana’s SPL Token program records approval on each token account, so there is no wallet-wide ERC-20 allowance list to review.

Solana stores each approval on a token account

When an owner submits an SPL Token Approve instruction, the token account stores a delegate address and the amount that delegate may transfer or burn. The delegate can act on that account up to the approved amount. Solana’s token documentation describes this account-level delegate model.

That storage location changes how you audit a wallet. On EVM chains, a token contract keeps allowances by spender, and one wallet may have separate allowances for several spenders against that token. On Solana, each token account has one current delegate field. A wallet can own multiple token accounts for the same mint, and each account needs its own inspection.

Take two token accounts for the same token. If you approve delegate A on the first account, then approve delegate B on that same account, B replaces A as its current delegate and allowance. A’s earlier approval is no longer recorded there. But if you approve A on one account and B on a second account, each account can retain its own delegate. An audit that checks only one account can therefore miss another active delegation.

Inspect delegate fields on Solscan or with the CLI

Solscan shows the delegate address and delegated amount on a token account page. Start with your wallet address, open its token accounts, and inspect each account’s details; confirm the account owner and mint so you know which wallet and asset the entry belongs to. A Solscan token account page displays both delegate fields.

For a command-line audit, list the wallet’s token accounts with spl-token accounts, then inspect each account address with spl-token display <TOKEN_ACCOUNT_ADDRESS>. Record the token account, mint, delegate, and delegated amount for every result. A missing delegate means that account has no current account-level delegate; a populated field identifies the current delegation to assess. The spl-token CLI reference documents the account and delegate commands.

This applies to the original SPL Token program and Token-2022 token accounts, but check the mint’s extensions too. Token-2022 can include a PermanentDelegate extension: it assigns authority at the mint level across token accounts, and an account owner cannot remove it with Revoke. That is separate from the ordinary delegate stored on an individual token account. Solana’s Token-2022 documentation explains the extension’s authority.

EVM allowance tools and Solana account delegates answer different questions. revokecash handles EVM-chain allowances; for this Solana audit, use Solscan or the Solana-native CLI to find token-account delegates. revokecash does not replace checking Solana token accounts or Token-2022 mint extensions.

Revoke unwanted delegates on their token accounts

Run spl-token revoke <TOKEN_ACCOUNT_ADDRESS> for each account whose delegate you want to clear. The account owner signs the revoke instruction, which removes that account’s current delegate and resets its delegated amount to zero. Repeat for each affected token account, then inspect the account again to confirm the fields are cleared. The Revoke instruction clears the account-level delegation.

Revoking a delegate clears the stored approval; it does not undo transfers the delegate already made. Nor does it remove a Token-2022 permanent delegate from a mint. Treat those as distinct findings when you review the wallet: one is an account-level approval you can revoke from the token account, while the other is a mint extension that the token account owner cannot clear.

Related

Does revokecash support Solana?

revokecash handles EVM-chain token allowances. Solana uses token-account delegates, so inspect and revoke them with Solana-native tools such as Solscan and spl-token.

How do Solana drainers take tokens without approvals?

A delegate audit finds persistent account-level approvals, not every way tokens can move. A wallet can also sign a transaction that directly transfers tokens, and a Token-2022 mint can carry a permanent delegate. Review transaction details and the mint’s extensions when an account shows no ordinary delegate but tokens moved or remain exposed.
