Why Is My Vault Withdrawal Pending in MetaMask?

Vault withdrawal transactions stuck pending in MetaMask are usually waiting on a higher fee or an earlier nonce. Speed up or replace the blocking transaction.

The Finality DeskNov 28, 2026 · 00:43 UTC4 min read#03dbac

A vault withdrawal transaction stuck pending in MetaMask has not been included in a block. Usually, its max fee is below the current base fee, or an earlier transaction from the same address is waiting ahead of it; validators skip underpriced transactions, and Ethereum processes each address’s nonces in order.

What keeps a withdrawal pending?

A signed withdrawal transaction carries a nonce and a fee limit that determine when it can be included. The nonce marks its place in the sequence of transactions sent from your address. The max fee sets the most you are willing to pay per unit of gas, while the base fee changes with network demand.

If the base fee rises above the transaction’s max fee, validators cannot include it under those terms. The transaction stays pending until the base fee falls enough or you replace the transaction with one offering a higher fee. A higher fee can help it get picked up, but it does not change the withdrawal request itself.

A lower nonce can hold up every later transaction from the same address. Say an approval has nonce 41 and is underpriced. Your withdrawal at nonce 42 must wait, even if its fee is sufficient. Speeding up nonce 41 can let that approval be included first, after which the withdrawal can proceed.

This distinction separates a wallet delay from a vault-side failure. Pending means the transaction has not been mined. A failed transaction was mined but reverted, and gas was spent. For a vault withdrawal, a request the vault cannot fulfil, such as one exceeding available liquidity, may fail on-chain. That is different from a pending transaction, which is usually a fee or nonce issue.

How to clear it and check the result

To clear a pending withdrawal, find the earliest unconfirmed transaction from your address and use MetaMask’s Speed up or Cancel option. Replacing a transaction requires the same nonce and a higher fee. Geth nodes require at least a 10% fee bump, though the replacement must still offer a fee that can get it included under current conditions.

Start by opening the transaction in MetaMask and copying its hash. Look it up on the relevant chain explorer: use Etherscan for Ethereum or Basescan for Base. If the explorer shows it as pending, speed it up in MetaMask. If the hash is missing, the transaction may have been dropped. Clear the activity data through Settings › Advanced › Clear activity tab data, then submit the withdrawal again.

Clearing activity data removes MetaMask’s local transaction history; it does not reverse an on-chain transaction. Before resubmitting, check the explorer and confirm the wallet’s pending transactions so you do not create another request while an earlier one is still active. If a replacement uses the same nonce, it competes with the original for inclusion; only one can be confirmed at that nonce.

Once a transaction is included, the explorer shows its status. A successful withdrawal is marked as successful; a revert is marked as failed and includes the mined transaction record. If the explorer confirms success but MetaMask still looks unchanged, refresh the wallet activity and check the transaction details on the explorer.

After the pending transaction clears, the remaining question may be how the vault’s withdrawal itself works. The steps for withdrawing from Morpho vaults can help at that point: Morpho vaults allocate deposits across lending markets and other supported yield sources, so the wallet transaction status and the vault’s available liquidity are separate things to check.

Related

Are my funds at risk while the withdrawal is pending?

Funds are not withdrawn by a transaction that remains pending, because it has not been included in a block. The signed request is waiting for a fee or earlier nonce to clear. Check the explorer before taking another action, especially before submitting a replacement or a new withdrawal.

Does cancelling a pending transaction cost gas?

Canceling through MetaMask sends a replacement transaction with the same nonce, so it must be mined to replace the pending request. If the cancellation is included, it uses gas; the original pending transaction is then displaced. Until the replacement is mined, the nonce remains unresolved and later transactions can still wait.
